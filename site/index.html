Features

Modular Architecture

Clean, layered design for easy extension and maintenance.

Concurrent Processing

Batch jobs processed in parallel for high throughput.

Flexible Channels

Support REST, gRPC, and custom channels out of the box.

Load Balancing

Client-side strategies like Round Robin ensure even distribution.

Transformation Rules

Apply powerful JSONata-based rules for data transformations.

Job Management

Track, pause, resume, and stop migrations with a built-in state machine.

How It Works

Bombardment simplifies your data migration process in four steps

1

Configure Your Source

Define your source data format (CSV, JSON, or custom formats) and connection details.

2

Define Transformations

Apply JSONata transformation rules to reshape your data for the target system.

3

Configure Target Channels

Set up REST or gRPC endpoints with load balancing strategies.

4

Execute & Monitor

Run batched migration jobs and track progress through the state machine.

Get Started
