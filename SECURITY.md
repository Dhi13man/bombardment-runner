# Security Policy

## Supported versions

Security fixes are provided for the latest release and the `main` branch.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Dhi13man/bombardment-runner/security/advisories/new). Do not open a public issue.

Include the affected version or commit, reproduction steps, impact, and any known workaround. Remove credentials, personal data, target-system data, and sensitive input files from the report.
